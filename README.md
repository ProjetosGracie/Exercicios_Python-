# 🐍 Exercícios de Python

## 📚 Sobre o repositório

Este repositório reúne uma coleção de **exercícios e práticas desenvolvidos em Python** ao longo do processo de aprendizado da linguagem.

Os exercícios foram desenvolvidos com o objetivo de praticar conceitos fundamentais de programação, evoluindo gradualmente desde estruturas básicas até problemas que exigem maior organização e lógica.

O repositório funciona como um **registro da evolução dos estudos em Python**, reunindo diferentes desafios, testes e implementações.

---

## 🎯 Objetivos

* Desenvolver lógica de programação;
* Praticar a sintaxe da linguagem Python;
* Aprender a estruturar soluções para diferentes problemas;
* Exercitar o uso de funções e estruturas de dados;
* Trabalhar com entrada e saída de dados;
* Desenvolver capacidade de resolução de problemas;
* Registrar a evolução durante o aprendizado da linguagem.

---

### 🔹 Estruturas de dados

### 🔹 Funções

* Criação de funções;
